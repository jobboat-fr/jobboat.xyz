3.Données non collectées JAMAIS

L'extension ne collecte jamais :

  • Votre historique de navigation ni les onglets ouverts
  • Le contenu des formulaires que vous saisissez manuellement
  • Les valeurs des champs de candidature après remplissage
  • Les mots de passe, données bancaires ou cookies tiers
  • Aucun outil d'analytics tiers (Google Analytics, Facebook Pixel, etc.)
  • Aucun identifiant publicitaire (IDFA, GAID)

4.Détection IA & sous-traitants

Lorsque la détection heuristique reconnaît moins de 3 champs sur un formulaire inhabituel, l'extension envoie une copie sérialisée et structurelle du DOM (libellés, attributs name, id, placeholder, aria-label, texte adjacent — jamais les valeurs saisies) à notre serveur, qui interroge à son tour Anthropic Claude 3.5 Haiku pour identifier le rôle de chaque champ.

  • Sous-traitant IA : Anthropic PBC, San Francisco, États-Unis. Politique de confidentialité Anthropic.
  • Encadrement juridique : Clauses Contractuelles Types (CCT) de la Commission européenne pour les transferts hors UE.
  • Anthropic s'engage à ne pas utiliser les données API pour entraîner ses modèles.
  • La clé API Anthropic est stockée côté serveur uniquement : elle n'est jamais exposée au navigateur.

5.Télémétrie anonyme

Pour mesurer la qualité de la détection sur chaque portail, l'extension envoie après chaque tentative d'auto-remplissage :

  • Le nom du portail (ex. indeed.fr) et le nom d'hôte
  • Le nombre de champs détectés et le nombre de champs remplis
  • La durée du traitement (ms) et la méthode utilisée (heuristique / adapter / IA)
  • Un éventuel message d'erreur technique

Aucune valeur saisie, aucun identifiant utilisateur (sauf si vous êtes connecté), aucune URL complète. Les statistiques agrégées sont publiques sur jobboat.xyz/stats.

6.Stockage et durée de conservation

  • Cache local (chrome.storage.local) : profil mis en cache 10 minutes pour limiter les appels réseau, puis rafraîchi.
  • Côté serveur JobBoat : événements de candidature conservés pendant la durée de votre compte, anonymisés après suppression de compte.
  • Côté Anthropic : les requêtes API sont conservées 30 jours pour la prévention des abus, puis supprimées (politique Anthropic).

7.Permissions Chrome demandées

  • activeTab : lire les champs de formulaire de l'onglet actif lors d'un clic sur « Auto-Fill ».
  • storage : mettre en cache votre profil et vos préférences localement.
  • scripting : injecter le détecteur de champs et lire la session Supabase depuis un onglet jobboat.xyz.
  • tabs : localiser un onglet jobboat.xyz ouvert pour récupérer la session.
  • host_permissions (9 portails d'emploi + JobBoat) : détecter les formulaires et communiquer avec l'API.

8.Partage et transferts hors UE

Aucune donnée n'est vendue, louée ou partagée à des fins publicitaires. Les seuls destinataires sont nos sous-traitants techniques :

  • Supabase Inc. (UE — Irlande) : hébergement de la base de données utilisateur
  • Railway Corp. (États-Unis) : hébergement du backend, sous CCT
  • Anthropic PBC (États-Unis) : détection IA des champs, sous CCT
  • SendGrid / Twilio (États-Unis) : envoi des emails transactionnels, sous CCT

10.Suppression des données stockées par l'extension

Vous pouvez à tout moment :

  • Cliquer « Déconnexion » dans le popup : efface session + profil cachés.
  • Désinstaller l'extension : Chrome efface automatiquement chrome.storage.local.
